# Graaly Academy in-game playground

Build it with npm ci followed by npm test, copy the whole directory into plugins, then run /academy.

- /academy opens all 36 theory checkpoints.
- /academy 8 opens the Effects lesson directly.
- Click Answer the checkpoint and type the answer in chat. Graaly captures that message as a controlled React input instead of publishing it.
- Scoreboard, boss bar, tab, inventory, chat messages, reducer state, list keys, derived progress, native input, and cleanup all come from one real React tree.

The [browser coding playground](https://sk8erboi17.github.io/Graaly/#academy) contains 208 Medium and Hard problems across the supported SDK modules and integrations: TypeScript, JavaScript, Python, C, React, FastAPI, Pydantic, raw ASGI, HTML/CSS, SQLite and YAML. Write code, run examples and submit edge tests. After an attempt, reveal hints and explained solutions. Drafts and progress persist on the device.

This native companion supplies theory checkpoints and real React game surfaces. Coding submissions execute in the browser playground. The downloadable workbook contains every problem statement and its editable starter files; C includes bitsets, shifts, unions, padding, serialization and ownership.
